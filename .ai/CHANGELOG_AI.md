Добавлены загрузка выбранного месяца, создание, изменение текста, перенос записи, мягкое удаление и транзакционная миграция legacy-данных с сохранением JSON до подтверждения успешного завершения.

  - `test/journal_database_test.dart`
  - `.ai/CHANGELOG_AI.md`
- **Проблемы, попытки и решения:**
  - *Проблемы:* инструмент не запускал Flutter-команды и не имел доступной рабочей копии для точечного обновления экрана `lib/pages/notes_page.dart`; поэтому экран пока продолжает читать прежний JSON и автономный слой не проверен компиляцией.
  - *Что пробовал:* изучил формат старых записей, выбрал UTC-хранилище для обеих временных меток и повторно безопасную миграцию. Для старых данных `createdAt` и `entryAt` принимаются как одно приближённое значение.
  - *Что сработало:* подготовлен атомарный миграционный путь без удаления исходного JSON до записи маркера успеха; прежний JSON остаётся управляемым SharedPreferences-ключом. Добавлены тесты операций хранения.
